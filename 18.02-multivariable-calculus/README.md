# 18.02SC Multivariable Calculus

Self-study of [MIT OpenCourseWare 18.02SC (Fall 2010, Prof. Denis Auroux)](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/), as part of my preparation for graduate study in computational neuroscience.

## Why this course

Multivariable calculus is the language of model fitting and dynamics in neuroscience: partial derivatives and gradients drive optimization, the Hessian describes curvature of error surfaces, and tangent approximations underlie the linearization of neuron models.

## How I work through it

1. Watch the session and make handwritten notes.
2. Attempt the problem set before checking any solutions.
3. Re-implement key ideas in Python (notebooks).
4. Write a short reflection on what was hard and what I got wrong.
